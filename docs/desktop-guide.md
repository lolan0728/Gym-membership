# 悦体健身 Windows 单机版使用与备份说明

## 启动与首次设置

1. 将“悦体健身会员管理_1.4.1_便携版.zip”完整解压到固定目录，例如 `D:\悦体健身会员管理`。
2. 双击“悦体健身会员管理.exe”启动。`resources` 文件夹必须与主程序放在一起，不能只复制EXE。
3. 首次打开后设置门店名称、联系电话、月卡天数、年卡天数和管理员密码。管理员密码至少8位，可以使用纯数字。
4. 默认月卡30天、年卡365天。以后修改只影响新的办卡和续卡，不会修改已有会员卡。
5. 备份目录默认是“文档\悦体健身\自动备份”。可填写QQ发件邮箱、收件邮箱和QQ邮箱SMTP授权码，也可以进入系统后再设置。收件邮箱留空时默认发送给发件邮箱。
6. 首次设置完成后会直接进入系统；以后每次完整关闭并重新启动都必须输入管理员密码。

## 日常使用

- 新办会员：在“会员管理”选择“新增会员”，填写姓名、手机号、卡种和日期。系统按月份自动生成会员号码，例如 `Y2026090001`。
- 续卡：在会员详情选择“办理续卡”。未到期会员从原到期日继续延长，已到期或作废会员默认从当天开始。

## 暂停、恢复与退卡（v1.4.0）

- 会员可在详情点击“暂停会员卡”，必须填写备注；窗口会提示该会员之前暂停过的次数。暂停中不计入有效、已到期和即将到期名单，不能直接续卡或修改卡片。
- 点击“恢复会员卡”可预览暂停开始日期、恢复日期、实际天数与新的到期日期。按北京时间自然日之差延长原到期日：9月1日暂停、10月1日恢复，加30天；同一天恢复加0天。开始日期不变，历史保留每次暂停备注和恢复天数。
- “退卡”位于会员卡操作行左侧，确认前显示已使用天数、已使用百分比和估算退款额，必须填写退卡原因。退卡只登记状态与估算，实际退款在线下办理。
- 已使用天数＝当前北京时间日期减当前会员卡开始日期，最少0天；减去本次有效期内的所有暂停天数（仍在暂停则扣至退卡日）。月卡以30天、99元为基准，年卡以365天、499元为基准，不跟随基础设置的卡期天数变化。
- 估算退款＝剩余比例×卡价，最终向上取整；使用达到或超过基准天数时为0元。按未舍入的比例计算，例如月卡使用13天，剩余17/30，退款为56.1元，显示57元。这里只是当前卡种的单次估算，不累计历次续费金额。
- 原有作废记录仍以“历史作废”保留，不会被当成已退款。新退卡在历史中保存原因和当时的估算金额，重新办卡可用“办理续卡”启用。

## 日期与预约提醒

- 暂停和恢复日期默认今天，可以改为过去或未来。过去及当天立即办理；未来日期保存为预约，到日自动生效。程序关机期间不会运行，下次启动会按原预约日期补执行。
- 可以先预约暂停，再预约恢复；详情页可修改或取消待执行预约。修改预约只接受未来日期；如需立即办理，先取消再办理。取消暂停会同时取消其关联恢复。待执行预约存在时，续卡、修改卡片、退卡需先取消预约。
- 暂停日期必须在对应有效期内且不早于上一段恢复日期；恢复日期不能早于暂停日。暂停次数只统计已实际执行的暂停。
- 顶部“日期提醒”包含开卡生效、临期（年卡30天/月卡7天）、到期失效及预约执行结果。到期当天仍有效，次日提示失效。暂停中不产生临期或到期提醒。
- 点击提醒进入会员详情并标记已读，也可全部已读；已读历史展示90天。系统保留去重标识，防止旧提醒再次出现。首次升级不补发全部历史生效提醒。
- 历史暂停记录缺失或异常会显示核查提醒并阻止不可靠的退款估算，不自动猜测或改写旧记录。

## PDF统计报表

打开左侧“统计报表”，选择月份后可查看新增会员、续卡会员、续卡时机、最近12个月趋势，以及即将到期和最近30天已到期未续卡名单。点击“导出月度报表 PDF”选择保存位置。

会员管理页右上角的“导出全部会员 PDF”始终导出完整会员名单，不受当前搜索、筛选和分页影响。月度新增会员按首次开卡的开始日期统计；续卡和作废按管理员实际办理时间统计。报表只读，不会修改会员资料或历史记录。
- 特殊期限：到期日期偏离当前设置的月卡或年卡天数时，必须填写备注。
- Excel批量导入：先下载当前模板。模板说明和校验会使用当前设置的月卡、年卡天数。
- 会员头像选填。新增或编辑会员时可点击选择本地JPEG/PNG照片，也可把照片直接拖入头像区域（最大5MB），调整方形裁剪预览后保存；可以替换或移除。详情和会员列表会显示头像，点击头像可查看大图；年卡、月卡卡面固定显示JOYFIT标志，不显示会员头像。头像保存在本机并随ZIP完整备份。普通Excel批量导入与PDF报表不含照片。单机版仍不显示微信绑定和小程序功能。

## 自动备份和QQ邮箱

1. 在“系统设置”的“完整自动备份”中设置本地目录、发件QQ邮箱、收件邮箱和每天备份时间。默认备份时间为13:00。
2. QQ邮箱中开启SMTP服务并取得授权码。程序需要的是授权码，不是QQ登录密码。
3. 授权码只保存在Windows凭据管理器，不写入数据库、日志或Excel。
4. 点击“发送测试邮件”验证邮箱设置，点击“立即完整备份”进行第一次正式备份。
5. 程序在设定时间运行自动备份；错过时间后会在下次启动补做当天的一次备份。同一天最多发送一封自动备份邮件，退出程序不会发送备份。
6. 邮件失败时ZIP仍保留在本地，程序会使用原备份文件重试，不会生成重复附件。“发送测试邮件”和“立即完整备份”是管理员主动操作，不受每日一次限制。
7. 默认保留最近30份本地备份，可在设置中调整。

## 操作日志

- 操作履历不包含在Excel备份、导出或恢复中，程序按月保存为UTF-8文本日志。
- 日志目录是 `%LOCALAPPDATA%\cn.joyfit.membership.desktop\logs`，文件名例如 `operations-2026-09.log`；可在“系统设置”点击“打开操作日志目录”。
- 更换电脑或只恢复Excel不会迁移这些本地日志，如需留存请另外复制日志目录。

## 恢复与升级

- “立即完整备份”会把完整ZIP保存到备份目录并按邮箱设置发送；“从完整备份恢复”会先保存当前数据，再校验并恢复所选备份。新版Excel不含操作履历，旧版v1备份中的“操作记录”在恢复时会被忽略。格式或数据校验失败时不会部分覆盖现有数据。
- 数据目录是 `%LOCALAPPDATA%\cn.joyfit.membership.desktop`。替换或移动便携版程序不会删除该目录。
- v1.4.0 新增暂停区间、预约和提醒数据，根据旧版历史补齐暂停区间，不重排会员号码、不改现有有效期、备注或历史。首次升级会先在数据目录下的 `upgrade-backups` 保存数据库快照，然后在事务中执行迁移；快照保存失败时不会继续升级。慢电脑首次升级可能需要等待一至两分钟。
- 建议升级前先在旧版执行“立即完整备份”，完整退出旧版后，将新版解压到另一个目录并启动；继续使用同一Windows用户即可读取原数据。不要同时运行不同版本，也不要删除数据目录。
- 新完整备份是v4 ZIP，包含members.xlsx（v3工作簿）、state.json（暂停区间、预约、提醒及已读状态）、avatars照片目录和manifest.json校验清单。不要单独用包内Excel恢复，否则会丢失照片和预约。支持恢复旧v1/v2/v3 Excel，界面会提前提示旧备份没有头像和预约。旧版程序不支持新暂停状态，升级后不要用旧版程序继续操作数据库。
- 升级时先退出程序，再用新版便携版文件替换旧版程序文件。更换电脑时，在旧电脑执行一次完整备份；新电脑解压程序、完成首次设置后，从该ZIP恢复。门店Logo图片需重新上传。
- 不要把自动备份目录放在程序安装目录内，也不要只保留电脑硬盘上的唯一副本。应确认QQ邮箱每天能够收到附件。
