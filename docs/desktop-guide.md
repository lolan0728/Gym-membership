# 悦体健身 Windows 单机版使用与备份说明

## 启动与首次设置

1. 将“悦体健身会员管理_1.2.1_便携版.zip”完整解压到固定目录，例如 `D:\悦体健身会员管理`。
2. 双击“悦体健身会员管理.exe”启动。`resources` 文件夹必须与主程序放在一起，不能只复制EXE。
3. 首次打开后设置门店名称、联系电话、月卡天数、年卡天数和管理员密码。管理员密码至少8位，可以使用纯数字。
4. 默认月卡30天、年卡365天。以后修改只影响新的办卡和续卡，不会修改已有会员卡。
5. 备份目录默认是“文档\悦体健身\自动备份”。可填写QQ发件邮箱、收件邮箱和QQ邮箱SMTP授权码，也可以进入系统后再设置。收件邮箱留空时默认发送给发件邮箱。
6. 首次设置完成后会直接进入系统；以后每次完整关闭并重新启动都必须输入管理员密码。

## 日常使用

- 新办会员：在“会员管理”选择“新增会员”，填写姓名、手机号、卡种和日期。系统按月份自动生成会员号码，例如 `Y2026090001`。
- 续卡：在会员详情选择“办理续卡”。未到期会员从原到期日继续延长，已到期或作废会员默认从当天开始。

## PDF统计报表

打开左侧“统计报表”，选择月份后可查看新增会员、续卡会员、续卡时机、最近12个月趋势，以及即将到期和最近30天已到期未续卡名单。点击“导出月度报表 PDF”选择保存位置。

会员管理页右上角的“导出全部会员 PDF”始终导出完整会员名单，不受当前搜索、筛选和分页影响。月度新增会员按首次开卡的开始日期统计；续卡和作废按管理员实际办理时间统计。报表只读，不会修改会员资料或历史记录。
- 特殊期限：到期日期偏离当前设置的月卡或年卡天数时，必须填写备注。
- Excel批量导入：先下载当前模板。模板说明和校验会使用当前设置的月卡、年卡天数。
- 单机版不采集会员头像，也不显示微信绑定和小程序功能。

## 自动备份和QQ邮箱

1. 在“系统设置”的“Excel自动备份”中设置本地目录、发件QQ邮箱、收件邮箱和每天备份时间。默认备份时间为13:00。
2. QQ邮箱中开启SMTP服务并取得授权码。程序需要的是授权码，不是QQ登录密码。
3. 授权码只保存在Windows凭据管理器，不写入数据库、日志或Excel。
4. 点击“发送测试邮件”验证邮箱设置，点击“立即完整备份”进行第一次正式备份。
5. 程序在设定时间运行自动备份；错过时间后会在下次启动补做当天的一次备份。同一天最多发送一封自动备份邮件，退出程序不会发送备份。
6. 邮件失败时Excel仍保留在本地，程序会使用原备份文件重试，不会生成重复附件。“发送测试邮件”和“立即完整备份”是管理员主动操作，不受每日一次限制。
7. 默认保留最近30份本地备份，可在设置中调整。

## 操作日志

- 操作履历不包含在Excel备份、导出或恢复中，程序按月保存为UTF-8文本日志。
- 日志目录是 `%LOCALAPPDATA%\cn.joyfit.membership.desktop\logs`，文件名例如 `operations-2026-09.log`；可在“系统设置”点击“打开操作日志目录”。
- 更换电脑或只恢复Excel不会迁移这些本地日志，如需留存请另外复制日志目录。

## 恢复与升级

- “立即完整备份”会把完整Excel保存到备份目录并按邮箱设置发送；“从完整备份恢复”会先保存当前数据，再校验并恢复所选备份。新版Excel不含操作履历，旧版v1备份中的“操作记录”在恢复时会被忽略。格式或数据校验失败时不会部分覆盖现有数据。
- 数据目录是 `%LOCALAPPDATA%\cn.joyfit.membership.desktop`。替换或移动便携版程序不会删除该目录。
- 升级时先退出程序，再用新版便携版文件替换旧版程序文件。更换电脑时，在旧电脑执行一次完整备份；新电脑解压程序、完成首次设置后，从该Excel恢复。门店Logo图片需重新上传。
- 不要把自动备份目录放在程序安装目录内，也不要只保留电脑硬盘上的唯一副本。应确认QQ邮箱每天能够收到附件。
