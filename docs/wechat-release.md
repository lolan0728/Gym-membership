# 微信接入与真机验收

## 开通与配置

1. 使用门店营业执照在微信公众平台注册非个人主体小程序，完成认证、适用服务类目选择及备案。实际材料和费用以账号后台为准。
2. 开通手机号实时验证能力并准备体验/付费额度。第一次领取或重绑时调用；日常查看卡片不重复调用。[官方说明](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/getRealtimePhoneNumber.html)
3. 在服务器私密环境变量中设置 AppID/AppSecret。根据微信后台要求配置服务器出口 IP 白名单，不把 AppSecret 写入小程序或前端。
4. 微信开发者工具导入 `apps/miniprogram`，把 `project.config.json` 的 `touristappid` 换成真实 AppID。把 `config.ts` 的 API_BASE 改为 `https://正式域名/api`。
5. 在小程序后台把该 HTTPS 域名加入 request、uploadFile、downloadFile 合法域名。正式包保持域名校验开启。
6. 在微信后台填写真实的用户隐私保护指引，覆盖手机号、用户选择的图片/头像、微信身份及会员档案处理，并填写运营主体、联系电话、保存政策及实际使用的云服务。[隐私授权接口说明](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/privacy/wx.requirePrivacyAuthorize.html)
7. 基础库至少 2.32.3，并选择支持实时手机号组件的版本进行调试。小程序内对首次领取做了能力检查，旧版微信提示更新。自定义隐私弹窗使用 `agreePrivacyAuthorization`，授权回调继续原请求。
8. 使用体验版联调，服务器 `WECHAT_QRCODE_ENV=trial`；正式发布后改成 `release`，在后台下载正式统一领卡码打印。所有码只包含公共门店场景，不含会员手机号或 ID。
