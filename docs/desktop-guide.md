# 悦体健身 Windows 单机版使用与备份说明

## 安装与首次设置

1. 运行“悦体健身会员管理_1.0.0_x64-setup.exe”。由于首版未购买代码签名证书，Windows可能显示“未知发布者”，请确认文件来自门店保存的安装包。
2. 首次打开后设置门店名称、联系电话、月卡天数、年卡天数和管理员密码。管理员密码至少12位。
3. 默认月卡30天、年卡365天。以后修改只影响新的办卡和续卡，不会修改已有会员卡。
4. 备份目录默认是“文档\悦体健身\自动备份”。可填写QQ发件邮箱、收件邮箱和QQ邮箱SMTP授权码，也可以进入系统后再设置。

## 日常使用

- 新办会员：在“会员管理”选择“新增会员”，填写姓名、手机号、卡种和日期。系统自动生成独立会员卡号。
- 续卡：在会员详情选择“办理续卡”。未到期会员从原到期日继续延长，已到期或作废会员默认从当天开始。
- 特殊期限：到期日期偏离当前设置的月卡或年卡天数时，必须填写备注。
- Excel批量导入：先下载当前模板。模板说明和校验会使用当前设置的月卡、年卡天数。
- 单机版不采集会员头像，也不显示微信绑定和小程序功能。

## 自动备份和QQ邮箱

1. 在“系统设置”的“Excel自动备份”中设置本地目录、发件QQ邮箱、收件邮箱和每天备份时间。
2. QQ邮箱中开启SMTP服务并取得授权码。程序需要的是授权码，不是QQ登录密码。
3. 授权码只保存在Windows凭据管理器，不写入数据库、日志或Excel。
4. 点击“发送测试邮件”验证邮箱设置，点击“立即完整备份”进行第一次正式备份。
5. 程序在设定时间运行自动备份；关闭程序时也会检查并补做。邮件失败时Excel仍保留在本地，下次启动会重试。
6. 默认保留最近30份本地备份，可在设置中调整。

## 恢复与升级

- “手动导出”下载完整Excel；“从完整备份恢复”会先保存当前数据，再校验并恢复备份。格式或数据校验失败时不会部分覆盖现有数据。
- 数据目录是 `%LOCALAPPDATA%\cn.joyfit.membership.desktop`。升级安装不会删除该目录。
- 更换电脑时，在旧电脑执行一次完整备份；新电脑安装程序、完成首次设置后，从该Excel恢复。门店Logo图片需重新上传。
- 不要把自动备份目录放在程序安装目录内，也不要只保留电脑硬盘上的唯一副本。应确认QQ邮箱每天能够收到附件。
