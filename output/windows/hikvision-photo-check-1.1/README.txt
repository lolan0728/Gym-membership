悦体健身：海康登记照片读取检测 v1.1（手机号查询）

使用位置：门店实际电脑，与 192.168.110.4 同一局域网。
无需安装 Node.js、Python 或开发工具，使用 Windows 自带 PowerShell 5.1。

1. 完整解压工具包到可写文件夹，不要直接在 ZIP 内运行。
2. 选择一名已经下发到门禁、已有登记照片的测试人员，准备其手机号。
3. 双击 start.cmd，输入11位手机号、设备用户名及设备密码。无需输入人员编号。
   注意使用门禁设备的密码，不是 iVMS-4200 软件的登录密码。
4. 等待检查完成，打开新生成的 results-日期-编号 文件夹。
5. report.json 是检测摘要；成功时还有 sample-photo.jpg，请在本机打开核对是否为该人员。

把 report.json 发给开发人员，并说明照片是否正确即可。无需发送密码或人员照片。
报告不保存密码、人员编号、姓名、手机号或照片下载地址。
照片只保存在本机结果目录。工具没有上传功能。

支持姓名格式：张三13800138000、张三 13800138000、张三　13800138000。
姓名与号码之间可有一个或多个普通/全角空格，末尾空格也可忽略。
手机号本身必须是完整连续的11位数字，工具不进行尾号或部分号码匹配。
工具分页核对门禁人员姓名，唯一匹配后自动取得内部人员编号并读取照片。
未找到、同一手机号匹配多名人员、姓名包含多个手机号或分页异常时，不会任选照片。
检测过程中的人员名单仅在内存中处理，不写入报告或文件。

此工具只验证接口，不会修改门禁人员、门禁权限或悦体健身会员数据。
POST 请求仅用于查询人员和人脸；没有新增、修改、删除或开门请求。
不依赖 iVMS-4200 持续运行，但测试人员及照片需已下发至门禁设备。
当前测试通用 ISAPI 的 Digest 认证及 blackFD / 1 人脸库。
失败可能是权限、认证、库编号、固件格式或底图保存设置等原因，不等同于设备不支持。
自动按手机号更新会员头像尚未接入，需要先通过实机验证。

常见结果：
- HTTP 401：核对设备用户名和密码，勿连续反复尝试。
- HTTP 403：核对账号权限或设备访问限制。
- 超时：核对门店电脑网络、设备地址和 HTTP 服务。
- 人员未找到：核对姓名末尾的完整手机号及是否已下发到这台门禁。
- 匹配多名人员：在 iVMS-4200 核对重复手机号后重新检测。
- 人员可读、照片不可读：保留报告，开发人员据此继续核对。

高级用法：如设备启用其他 HTTP 端口或 HTTPS，可在 PowerShell 中运行：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\check.ps1 -DeviceAddress "https://192.168.110.4"
工具不忽略 HTTPS 证书错误、不自动跟随跳转、不向其他地址发送设备密码。

依据：海康明眸门禁 ISAPI 官方文档（人员查询、人脸图片查询）。
